# A股量化交易策略系统

> 面向**个人投资者**的半自动化A股交易辅助工具。
> 策略输出操作建议，**人工确认后手动下单**，不自动执行交易。

---

## 核心理念

```
政策/新闻 → LLM分析受益主题 → 宇宙库动态选股 → 技术信号精确扫描 → 你手动下单
```

- **选什么（动态）**：LLM分析当日政策消息面，推荐受益主题关键词（如"算力"、"光伏"、"银行"）；选股器从128只主板股票宇宙里按关键词+流动性+趋势动态筛出候选
- **什么时候买**：多因子技术策略（MA趋势+RSI+MACD+量能）对候选跑精确信号，识别回调买点
- **怎么买**：固定仓位管理（每笔28%≈4.2万），最多同时持仓3只
- **怎么卖**：盈利达+3%后激活**追踪止损**（从最高价回撤5%离场），让趋势股充分奔跑；止损-7%跌破必须执行

### 1. 安装依赖

```bash
pip install baostock pandas pyarrow numpy scikit-learn xgboost matplotlib
pip install anthropic  # LLM板块分析（可选）
```

### 2. 下载真实行情数据（在本地有网络的机器上运行一次）

```bash
# 下载所有板块股票的历史数据（2020至今），保存到 data/cache/
python data/download_baostock.py

# 只下载特定板块
python data/download_baostock.py --sectors AI与科技 金融

# 验证缓存完整性
python data/download_baostock.py --verify

# 补充最新数据（断点续传，只下增量）
python data/download_baostock.py --end 2026-03-10
```

> **数据格式**：`data/cache/{股票代码}.parquet`（前复权日线，字段：open/high/low/close/volume/amount/turnover/pct_chg）

### 3. 每日扫描（核心工作流）

```bash
# 方式A：手动指定主题（可以是板块名或行业关键词）

python run_daily_scanner.py --sectors 算力 光伏 银行   # 也支持关键词

python run_daily_scanner.py --news "央行宣布降准0.5个百分点..."

# 查看所有主题 + 宇宙股票统计
python run_daily_scanner.py --list-sectors
```

## 策略原理

### 买入信号（需全部满足）

| 条件 | 参数 | 含义 |
|------|------|------|
| MA趋势 | 收盘 > MA60，且MA60 > MA120 | 中长期趋势向上 |
| **牛市体制** | MA60向上 + (价格>MA120 或 MA120向上) | 过滤熊市噪声，仅在牛市做多 |
| 回调确认 | 收盘 < MA20 或布林带下半区 | 回调到位，不追高 |
| RSI | 40 ≤ RSI ≤ 68 | 未超买，有上升空间 |
| MACD | DIF穿越DEA（金叉），或MACD柱转正 | 短期动能翻转 |
| 量能 | 成交量 ≥ 均量 × 1.0 | 有效突破需要量配合 |
| ADX | ADX > 20（趋势强度） | 过滤震荡行情 |

### 信号强度评分（★1-5）

每满足一个附加条件得1星：
1. MA60向上倾斜（趋势加速）
2. RSI在45-65健康区间
3. MACD柱状量转正
4. 成交量放大1.2x以上
5. 价格站上MA60

### ML过滤器（可选）

用 XGBoost 对历史信号做二次过滤，剔除低胜率信号。特征包含20+个技术指标，训练用前70%数据，验证用后30%。

### 组合管理

- 同日多信号时，按**综合评分**排序（ADX强度30% + 买入评分30% + RSI30% + ML概率20%），取前3只
- 最多同时持仓3只，新信号触发时若已满仓自动忽略

## 止盈止损数学依据

在牛市体制（μ=0.10%/日，σ=1.5%/日）下，用布朗运动理论推导：

```
θ = 2μ/σ² = 2×0.001/0.015² ≈ 8.89

P(先涨3%再跌8%) = (1 - e^{-θ×0.08}) / (1 - e^{-θ×0.11}) ≈ 83%

期望值 = 0.83×3% + 0.17×(-8%) = +1.13%/笔
扣费后净期望 ≈ +0.77%/笔
```

设置止盈3% / 止损8% 的理论胜率约83%，实测仿真约87%（牛市）。

## 回测结果

### 历史回测（2023-2026.02，仿真数据）

追踪止损 + 牛市体制过滤策略，15万初始资金：

| 指标 | 结果 | 达标 |
|------|------|------|
| 年化收益率 | 13.73% | ✅ ≥10% |
| 最大回撤 | 5.65% | ✅ ≤20% |
| 夏普比率 | 1.69 | ✅ ≥1.0 |
| 盈亏比 | 2.49 | ✅ ≥1.5 |
| 月度胜率 | 70.83% | ✅ ≥60% |
| 综合评级 | 优秀 4/5 | ✅ |

**年度明细**：2023 待补充 / 2024 +9.4% / 2025 +19.8% / 2026前两月 +3.1%

详见 [BACKTEST_RESULTS.md](BACKTEST_RESULTS.md)

### 追踪止损 vs 固定止盈对比

| 策略 | 年化收益 | 最大回撤 | 夏普 | 平均盈利 |
|------|----------|----------|------|----------|
| 固定止盈+3% | -0.6% | — | — | +3% |
| **追踪止损（当前）** | **13.73%** | 5.65% | 1.69 | ~+11% |

追踪止损让趋势股充分奔跑，不过早止盈，年化从 -0.6% 提升至 13.73%。

**结论**：策略对趋势市场友好；牛市体制过滤在熊市/震荡市自动减少交易，降低损耗。

## 数据流说明

```
data/download_baostock.py       ← 本地有网时运行一次
         │ 保存前复权日线
         ▼
data/cache/{code}.parquet       ← 本地缓存（长期有效）
         │
         ▼
data/fetcher.load_cache()       ← 所有脚本统一读取入口
         │ 无缓存时fallback
         ▼
generate_synthetic_data()       ← 仿真数据（开发/测试用）
```

**所有回测和扫描脚本无需额外配置，自动检测本地缓存并使用真实数据。**

## 每日操作流程

```
收盘后（15:30之后）
  1. 打开今日财经新闻/政策公告
  2. 运行扫描器（LLM选板块 或 手动选板块）
  3. 查看输出的买入建议
  4. 结合自己对新闻的判断，决定是否下单
  5. 若下单：在券商APP同时设置止损预警（-8%）和止盈挂单（+3%）

注意事项：
  · 已满3只仓位时忽略新信号
  · 持仓超过30个交易日未到止盈/止损，手动平仓
  · 高波动期间（市场日内振幅持续>3%）建议暂停操作
```
