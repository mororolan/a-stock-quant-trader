# A股量化交易策略系统

> 面向**个人投资者**的半自动化A股交易辅助工具。
> 策略输出操作建议，**人工确认后手动下单**，不自动执行交易。

---

## 核心理念

```
政策/新闻 → LLM分析受益板块 → 技术信号扫描 → 输出操作建议 → 你手动下单
```

- **选什么**：LLM（Claude）分析当日政策消息面，推荐受益板块
- **什么时候买**：多因子技术策略（MA趋势 + RSI + MACD + 量能）识别回调买点
- **怎么买**：固定仓位管理（每笔28% ≈ 4.2万），最多同时持仓3只
- **怎么卖**：止盈+3%挂限价单，止损-8%跌破必须执行


### 2. 下载真实行情数据（在本地有网络的机器上运行一次）

```bash

# 只下载特定板块

# 补充最新数据（断点续传，只下增量）
python data/download_baostock.py --end 2026-03-10
```

## 策略原理

### 买入信号（需全部满足）

| 条件 | 参数 | 含义 |
|------|------|------|
| MA趋势 | 收盘 > MA60，且MA60 > MA120 | 中长期趋势向上 |
| 回调确认 | 收盘 < MA20 或布林带下半区 | 回调到位，不追高 |
| RSI | 40 ≤ RSI ≤ 68 | 未超买，有上升空间 |
| MACD | DIF穿越DEA（金叉），或MACD柱转正 | 短期动能翻转 |
| 量能 | 成交量 ≥ 均量 × 1.0 | 有效突破需要量配合 |
| ADX | ADX > 20（趋势强度） | 过滤震荡行情 |

### 信号强度评分（★1-5）

每满足一个附加条件得1星：
1. MA60向上倾斜（趋势加速）
2. RSI在45-65健康区间
3. MACD柱状量转正
4. 成交量放大1.2x以上
5. 价格站上MA60

### ML过滤器（可选）

用 XGBoost 对历史信号做二次过滤，剔除低胜率信号。特征包含20+个技术指标，训练用前70%数据，验证用后30%。

### 组合管理

- 同日多信号时，按**综合评分**排序（ADX强度30% + 买入评分30% + RSI30% + ML概率20%），取前3只
- 最多同时持仓3只，新信号触发时若已满仓自动忽略

## 止盈止损数学依据

在牛市体制（μ=0.10%/日，σ=1.5%/日）下，用布朗运动理论推导：

```
θ = 2μ/σ² = 2×0.001/0.015² ≈ 8.89

P(先涨3%再跌8%) = (1 - e^{-θ×0.08}) / (1 - e^{-θ×0.11}) ≈ 83%

期望值 = 0.83×3% + 0.17×(-8%) = +1.13%/笔
扣费后净期望 ≈ +0.77%/笔
```

设置止盈3% / 止损8% 的理论胜率约83%，实测仿真约87%（牛市）。

## 数据流说明

```
data/download_baostock.py       ← 本地有网时运行一次
         │ 保存前复权日线
         ▼
data/cache/{code}.parquet       ← 本地缓存（长期有效）
         │
         ▼
data/fetcher.load_cache()       ← 所有脚本统一读取入口
         │ 无缓存时fallback
         ▼
generate_synthetic_data()       ← 仿真数据（开发/测试用）
```

**所有回测和扫描脚本无需额外配置，自动检测本地缓存并使用真实数据。**

## 每日操作流程

```
收盘后（15:30之后）
  1. 打开今日财经新闻/政策公告
  2. 运行扫描器（LLM选板块 或 手动选板块）
  3. 查看输出的买入建议
  4. 结合自己对新闻的判断，决定是否下单
  5. 若下单：在券商APP同时设置止损预警（-8%）和止盈挂单（+3%）

注意事项：
  · 已满3只仓位时忽略新信号
  · 持仓超过30个交易日未到止盈/止损，手动平仓
  · 高波动期间（市场日内振幅持续>3%）建议暂停操作
```
